Aplikasi web sederhana untuk pencatatan dan pengelolaan penyewaan kostum cosplay yang disusun bertahap menggunakan **HTML**, **CSS**, dan **JavaScript**.

## Progres & Fitur Saat Ini (Minggu 1 / Tahap 1)
- **HTML (`index.html`):** Menyusun struktur halaman utama, form input pencatatan (keterangan, nominal/jumlah, dan pilihan jenis), serta tampilan awal daftar catatan.
- **CSS (`style.css`):** Mengatur tata letak form, kartu konten, dan daftar dengan kombinasi warna putih, ungu, serta warna teks gelap yang sederhana dan mudah dibaca.
- **JavaScript (`app.js`):** Menambahkan penanganan dasar saat form disubmit (`event.preventDefault()`) dan pesan info awal sebelum logika dinamis lanjutan ditambahkan pada minggu berikutnya.

## Catatan Branch
- `master`: Berisi dokumentasi proyek (`README.md`) yang dikelola melalui branch dan commit `chore`.
- Branch fitur terpisah: Menampung pengembangan kode HTML, CSS, dan JavaScript tahap awal (belum digabung ke `master`).
